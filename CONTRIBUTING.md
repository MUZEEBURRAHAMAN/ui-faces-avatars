# Contributing

Thanks for your interest in Avatarly.

## What We Accept

- **Bug reports** — broken images, incorrect metadata, missing files
- **Metadata improvements** — better tags, corrected color data, typo fixes
- **Script improvements** — performance, new features for processing tools
- **Documentation fixes** — typos, broken links, unclear instructions

## What We Don't Accept

- Avatar image submissions (all avatars are internally curated)
- New collection proposals (planned internally)
- Changes to licensing terms

## How to Contribute

1. Open an issue describing the problem or improvement
2. Fork the repository
3. Make your changes in a feature branch
4. Submit a pull request with a clear description

## Code Style

- Scripts: Node.js ESM (`import`/`export`), no TypeScript
- JSON: 2-space indent, trailing newline
- File names: kebab-case, lowercase

## Reporting Issues

Include:
- Collection name and avatar ID
- Expected vs actual behavior
- Screenshot if visual issue
