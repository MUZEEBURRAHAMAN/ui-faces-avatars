# Changelog

## [1.0.0] - 2026-08-30

### Added
- Initial release with 11 collections (518 total avatars)
- Office Avatars (72), Everyday Avatars (45), Human Avatars (30)
- Company Avatars (42), Abstract Avatars (30), Sculpted Avatars (30)
- Doodle Avatars (32), Illustrated Avatars (30), Cartoon Avatars (30)
- Quiet Avatars (30), People Bundle (147)
- 4K PNG originals, 800px JPG previews, 200px WebP thumbnails
- JSON metadata for all collections and individual avatars
- Batch processing scripts (resize, compress, convert)
- GitHub Actions workflow for auto-optimization
